EXPERIMENT 18 - GYM MEMBERSHIP MANAGEMENT SYSTEM

CONTENTS
1. Experiment_18_Gym_Membership.sql - complete MySQL script
2. Experiment_18_Report.docx - editable practical record write-up
3. README.txt - instructions

TABLES
- membership_plans: plan name, duration, fee and description
- trainers: trainer name, phone and specialization
- members: member details and assigned trainer
- subscriptions: member plan, start/end dates and payment status

HOW TO USE
1. Extract this ZIP file.
2. Open the SQL file in MySQL Workbench (when available).
3. Connect to your MySQL Server.
4. Execute the complete script using the lightning icon.
5. Refresh Schemas and open gym_membership_db.

IF MYSQL WORKBENCH IS NOT WORKING
Use a MySQL 8.0-compatible online SQL environment. Some online SQL
editors do not support stored procedures or DELIMITER; in that case,
run the script up to the VIEW section and execute the stored procedure
part separately in a compatible MySQL server.

NOTE
This is a sample academic database. Update the student name, roll number,
college details and experiment date in the report before submission.
